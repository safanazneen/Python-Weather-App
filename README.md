# 🌦️ Python Weather App

A Python application that fetches current weather information for cities using the Open-Meteo API.

## Features
- Search weather by city name
- Display temperature in Celsius
- Show humidity percentage
- Display wind speed in km/h
- Show city and country information

## Technologies Used
- Python
- Open-Meteo API
- JSON
- urllib

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run the command:

```bash
python weather_app.py
```

4. Enter a city name to view its weather report.

## How It Works
The application finds the city's coordinates using the Open-Meteo geocoding service, retrieves current weather information, and displays temperature, humidity, and wind speed.
